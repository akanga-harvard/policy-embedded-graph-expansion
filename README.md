The ICPSR dataset is publicly available and can be downloaded at doi.org/10.3886/ICPSR22140.v1. See citation below. Move all three tsv data files into data folder.

To run main experiment, set experiment = 1 in the main function of simlator.py. To run the ablation study, set experiment = 2. Then, run simulator.py

Much of the Gittins index-based oracle and DQN code is originally from: https://github.com/cxjdavin/adaptive-frontier-exploration-on-graphs/


Martina Morris and Richard Rothenberg. HIV Transmission Network Metastudy Project: An Archive of Data From Eight Network Studies, 1988–2001 (ICPSR 22140). ICPSR Data Holdings, 2011. Available at doi.org/10.3886/ICPSR22140.v1.
